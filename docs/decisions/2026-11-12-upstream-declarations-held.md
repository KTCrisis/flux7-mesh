# A new or changed upstream declaration is held until an operator accepts it

- **Problem**: with hot reload, a `command:` line added to the config file was executed within a second, and a server seen for the first time was trusted on first use. The restart it replaced was a human act; nothing had taken its place. The file is writable by anything that can write files as the mesh's user, and an agent whose policy allows a file-writing tool is such a thing: it could make the mesh run a program, which is leaving the mesh's governance. Raised in review before the release.
- **Decision**: a declaration that appears or changes while the mesh runs starts nothing. It is held (`upstreams.Propose`), the declaration it would replace keeps running, and `POST /mcp-servers/{name}/accept` (`mesh7 upstream accept <name>`, the console) starts it. `GET /mcp-servers/held` shows what each would run: command and arguments or URL, names of env and header keys, never their values; admin only. Removing a declaration is applied at once. Declarations read when the daemon starts are trusted as they are. A file change that holds or removes something is recorded as `mesh.upstream_file_change`, an accept as `mesh.upstream_accept`.
- **Why**: the mesh cannot assume its files are protected elsewhere, and it already refuses to make a new or changed tool callable without an accept (pinning); a program it would execute deserves at least that. What is kept from hot reload: no restart, no cut for the other upstreams, removals at once.
- **Limits**: without `auth.admin_token` any local process can call the control plane, `accept` included; the hold stops an agent confined to mesh tools, not one with a shell. Policy files are still applied on change: an agent that can write `policy_dir` can widen its own rights. Keep the config and `policy_dir` out of reach of what agents can write.
- **Where**: `cmd/mesh7/upstreams.go` (`Propose`, `Held`, `Accept`), `cmd/mesh7/mesh.go`, `proxy/upstreams.go`, `internal/opcli/upstream.go`; tests `TestUpstreamsProposeHoldsNewAndChangedDeclarations`, `TestUpstreamsProposeWithdrawnOrRevertedIsNoLongerHeld`, `TestUpstreamsProposeRemovesAtOnce`.
